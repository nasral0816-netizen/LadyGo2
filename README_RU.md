# LadyGo — описание проекта

LadyGo — Android-приложение сервиса поездок с интерфейсами пассажира, водителя и администратора.

## Что найдено в клиентском коде

- Регистрация и вход через Supabase Auth (email/пароль).
- Карта MapLibre, определение места подачи через Expo Location.
- Поиск адресов и построение автомобильного маршрута с внешними сервисами и резервными источниками.
- Создание и просмотр заказов, выбор тарифа и способа оплаты.
- Получение координат назначенного водителя и передача координат со стороны приложения водителя.
- Realtime-обновление заказов и чат участников поездки.
- Интерфейсы пассажира, водителя и администратора.
- Вызовы Supabase RPC и Edge Function для ценообразования.

Наличие этих экранов и вызовов не означает, что backend-часть уже полностью доступна. Несовпадения клиентского контракта и SQL-миграций описаны в [AUDIT_RU.md](./AUDIT_RU.md).

## Локальная настройка

1. Установи Node.js 22.
2. Скопируй `.env.example` в `.env`.
3. Укажи URL Supabase и публичный anon/publishable key.
4. Выполни `npm install`.
5. Проверь Expo: `npx expo config --type public`.
6. Запусти `npx expo start`.

## Сборка Android

Открой GitHub Actions → Android APK Build → Run workflow. После успешной сборки APK будет доступен в Artifacts.

## Важно

Не применяй SQL-миграции к production до проверки фактической схемы Supabase. Не добавляй в репозиторий `.env`, service-role key, приватные токены, пароли или персональные данные. Репозиторий публичный.
